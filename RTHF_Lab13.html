Inyección SQL basada en errores visibles

Nombre del laboratorio

Inyección SQL basada en errores visibles.

Nivel

Practitioner.

Tipo de SQLi

In-band SQLi (Error-based).

Objetivo del laboratorio

Extraer la contraseña del usuario administrator de la tabla users y realizar un inicio de sesión exitoso con dichas credenciales.

Explicación técnica

El laboratorio presenta una vulnerabilidad en el manejo de cookies de rastreo (tracking cookies).
Punto de Inyección: La aplicación concatena directamente el valor de la cookie en una consulta SQL.
Mecanismo de Error: La aplicación muestra errores detallados de la base de datos cuando una consulta falla.
Estrategia de Explotación: Se inyecta sintaxis SQL maliciosa que fuerce un error de conversión o tipo de dato.
Fuga de Datos: El atacante obtiene información sensible al leer los mensajes de error generados.

Procedimiento paso a paso

Acceso inicial

Acceder a la instancia desde el navegador integrado de BurpSuite y localizar la cookie TrackingId en el historial HTTP.

Imagen 1

Confirmación de vulnerabilidad

Enviar la petición al Repeater y añadir una comilla simple al valor de la cookie. Observar el error SQL en la respuesta.

Imagen 2

Prueba con comentarios y CAST

Añadir -- y probar con AND CAST((SELECT 1) AS int)--. Ajustar la sintaxis para que sea válida: AND 1=CAST((SELECT 1) AS int)--.

Imagen 3 Imagen 4

Enumeración de usuarios

Payload: TrackingId=' AND 1=CAST((SELECT username FROM users LIMIT 1) AS int)--. El primer usuario devuelto es administrator.

Imagen 5

Extracción de contraseña

Payload: TrackingId=' AND 1=CAST((SELECT password FROM users LIMIT 1) AS int)--. La contraseña filtrada es n0qruhn61643ghsw146z.

Imagen 6

Inicio de sesión

Usar las credenciales obtenidas (administrator / n0qruhn61643ghsw146z) para iniciar sesión y resolver el laboratorio.

Imagen 7

Mitigación recomendada

Consultas Preparadas: Utilizar sentencias parametrizadas para evitar concatenación directa.
Desactivar mensajes de error detallados: Configurar errores genéricos para el usuario final.
Validación de entrada: Restringir el formato de la cookie de rastreo mediante expresiones regulares.
