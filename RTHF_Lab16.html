Blind SQL injection with out-of-band interaction

Nombre del Laboratorio

Blind SQL injection with out-of-band interaction.

Nivel

Practitioner (Nivel Intermedio).

Tipo de SQLi

Out-of-band SQL Injection (OAST).

Objetivo del Laboratorio

Explotar la vulnerabilidad de inyección SQL para forzar una consulta DNS hacia el servidor de Burp Collaborator.

Explicación Técnica de la Vulnerabilidad

La aplicación utiliza una cookie de rastreo (TrackingId) que es procesada por la base de datos de forma asíncrona. Debido a esto, la aplicación no devuelve errores ni cambios en el contenido de la página (Blind). Sin embargo, Oracle permite el uso de funciones como EXTRACTVALUE y xmltype que pueden ser manipuladas para realizar peticiones externas. Al inyectar un ataque de XXE dentro del SQLi, se obliga al servidor a interactuar con un dominio externo controlado por el atacante.

Confirmación de vulnerabilidad

Tras inyectar el payload OAST en la cookie y aplicar codificación URL, el servidor responde con estado 200 OK. Esto confirma que la base de datos procesó la inyección y ejecutó la interacción externa solicitada.

Imagen 7

Confirmación de Laboratorio Resuelto

En Burp Suite Repeater se observa que tras enviar la petición con el payload codificado, el servidor responde con HTTP/2 200 OK. Esto confirma la vulnerabilidad y la capacidad de provocar interacciones externas.

Explicación del Payload

x' UNION SELECT...: Rompe la cadena original y añade una consulta personalizada.
EXTRACTVALUE(): Función de Oracle que extrae datos de un XML, usada aquí como disparador.
xmltype(): Crea un documento XML con una entidad externa.
http://BURP-COLLABORATOR-SUBDOMAIN/: Dirección del atacante para forzar la petición DNS.
--: Comenta el resto de la consulta original para evitar errores de sintaxis.

Mitigación Recomendada

Sentencias Preparadas: Usar consultas parametrizadas para tratar la cookie como texto.
Validación y Saneamiento: Filtrar cookies para que solo contengan caracteres alfanuméricos.
Hardening de la Base de Datos: Configurar Oracle para que el usuario de la aplicación no tenga permisos de ejecutar funciones XML ni peticiones externas.
