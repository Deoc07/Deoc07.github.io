SQL injection attack, listing the database contents on non-Oracle databases

Nombre del Laboratorio

SQL injection attack, listing the database contents on non-Oracle databases.

Nivel

Practitioner (Nivel Intermedio).

Tipo de SQLi

UNION-based SQL Injection (Enumeración de esquema).

Objetivo del Laboratorio

Extraer los nombres de las tablas y columnas sistemáticamente para localizar la tabla de usuarios, obtener la contraseña del usuario administrator e iniciar sesión en su cuenta.

Explicación Técnica de la Vulnerabilidad

La vulnerabilidad reside en el parámetro category, el cual es vulnerable a inyecciones basadas en UNION. Al ser una base de datos PostgreSQL, la aplicación permite consultar el catálogo de metadatos information_schema. Esto es crítico porque permite a un atacante reconstruir toda la estructura de la base de datos (nombres de tablas y columnas) aunque estos hayan sido ofuscados o generados aleatoriamente por el sistema.

Procedimiento Paso a Paso

Intercepción

Capturar la petición GET del filtro de categorías en Burp Suite y enviarla al Repeater.

Determinación de Columnas

Se confirmó que la consulta devuelve 2 columnas usando ' ORDER BY 2-- y que ambas aceptan texto.

Enumeración de Tablas

Se consultó la tabla de metadatos para buscar la tabla de usuarios del laboratorio.
Payload: ' UNION SELECT table_name, NULL FROM information_schema.tables--
Resultado: Se identificó la tabla users_faborn.

Enumeración de Columnas

Se buscaron los nombres de las columnas dentro de la tabla encontrada.
Payload: ' UNION SELECT column_name, NULL FROM information_schema.columns WHERE table_name='users_faborn'--
Resultado: Columnas username_ifjekb y password_enyhpp.

Extracción de Credenciales

Se ejecutó el SELECT final para obtener los datos de la cuenta administrator.

Acceso

Inicio de sesión exitoso en el navegador de Kali.

Explicación del Payload

' UNION SELECT username_ifjekb, password_enyhpp FROM users_faborn--
': Rompe el cierre de la cadena original en la consulta SQL.
UNION SELECT: Permite añadir una segunda consulta a la principal.
username_ifjekb, password_enyhpp: Son los alias internos que la base de datos asignó a las columnas de usuario y contraseña.
FROM users_faborn: Indica la tabla específica donde reside el registro de administrador.
--: Comenta el resto de la consulta original para evitar errores de sintaxis en el servidor.

Mitigación Recomendada

Uso de Sentencias Preparadas (Prepared Statements): Es la defensa más efectiva, ya que separa los datos del comando SQL.
Validación de Entradas: Aplicar un filtrado estricto (Whitelist) para que el parámetro category solo acepte valores predefinidos.
Hardening de Base de Datos: Limitar los privilegios del usuario de la aplicación para que no pueda consultar tablas del sistema como information_schema.
