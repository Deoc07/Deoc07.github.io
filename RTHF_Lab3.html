SQL injection attack, querying the database type and version on Oracle

Nombre del laboratorio

SQL injection attack, querying the database type and version on Oracle.

Nivel

Practitioner.

Tipo de SQLi

In-band (UNION-based).

Objetivo del laboratorio

Ejecutar un ataque de unión para extraer metadatos del sistema (versión) en una base de datos Oracle.

Explicación técnica

Oracle requiere una estructura de consulta UNION muy precisa: el número de columnas debe coincidir exactamente con la consulta original y toda sentencia debe incluir la cláusula FROM. Se utiliza la tabla v$version para obtener la información del banner del sistema.

Procedimiento paso a paso

Determinación de Columnas y Prueba de Compatibilidad de Datos

Enviar la petición de categoría al Repeater. Probar la cantidad de columnas inyectando ' ORDER BY 1--, ' ORDER BY 2--, etc., para recibir un error 500. Esto confirma que existen 2 columnas. Para confirmar que las columnas aceptan datos de tipo cadena, inyectar: category=Accessories' UNION SELECT NULL, NULL FROM DUAL--. El uso de DUAL es obligatorio en Oracle para consultas que no apuntan a una tabla de usuario.

Explicación del payload

' UNION SELECT banner, NULL FROM v$version--
banner: Es el nombre de la columna predefinida en Oracle que contiene la versión.
v$version: Vista de rendimiento fija que contiene información sobre la versión de los componentes del servidor.

Mitigación recomendada

Aplicar el principio de Mínimo Privilegio, asegurando que el usuario de conexión de la base de datos no tenga permisos de lectura sobre las vistas v$ ni tablas de catálogo.
